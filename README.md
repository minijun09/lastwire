# LAST WIRE · 마지막 전선

전선을 자르며 보상 배수를 쌓는 브라우저 폭탄 해체 로그라이트입니다.

**[바로 플레이](https://minijun09.github.io/lastwire/)**

## 플레이

- PC: 전선에 마우스를 올려 기폭 확률과 성공 배수를 확인하고, 클릭해서 절단합니다.
- 모바일: 전선을 한 번 터치해 확인하고, 같은 전선을 다시 터치해서 절단합니다.
- 정산하고 철수하면 현재 보상이 보유 자금에 입금됩니다.
- 폭탄 4개마다 검수합니다. 목표를 넘기면 자금과 장비를 유지한 채 다음 계약으로 넘어갑니다.
- 목표는 1천 → 5천 → 2만 → 7만 → 20만원, 이후 계약마다 1.8배씩 증가합니다. 작업 횟수 제한은 없습니다.
- 검수 목표 미달 또는 생존 장비 3개 소진 시 종료됩니다.
- 장비는 최대 4개 장착합니다. 상점에서 구매하거나 기존 장비를 교체할 수 있습니다.

키보드: `1–6` 전선 선택 · `Space` 절단 · `Enter` 정산. 효과음은 기본 OFF이며 설정 메뉴에서 변경합니다.

## 로컬 실행

별도 설치나 빌드 없이 실행합니다.

```sh
python3 -m http.server 4173
```

[http://localhost:4173](http://localhost:4173)에 접속하세요.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. `main`에 파일을 푸시하면 사이트가 자동 갱신됩니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.

HTML / CSS / JavaScript로 구성되며, 최고 기록과 테마는 브라우저에 저장됩니다.
